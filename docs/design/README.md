## 阅读顺序（按角色）

- **要了解全局**：`00` → `01` → `10` → `11`
- **要写后端**：`02` → `03` → `05` → `08` → `11`
- **要写前端**：`02` → `04` → `06` → `07` → `11`
- **要评审/验收**：`10` → `11` → `13` → `09`
- **要同步上游**：`12` → `10`

## 纪律（三条，违反即回退）

1. **对等矩阵是唯一的功能真源**：功能只有进了 `10-parity-matrix.md` 并且有验收方式，才算要做的。
2. **边界与死角必须显式**：新功能的边界值必须在 UI 可见；死角必须有复审触发条件。
3. **文档先于代码**：改设计先改本目录，代码跟上；不允许「代码上了文档没写」。
