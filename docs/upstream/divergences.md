# 有意偏离清单（divergences）

本文与 `docs/design/12-legacy-and-upstream.md` §5 的 DIV-01..DIV-10 一一对应，
并由 `make upstream-radar`（`scripts/check-upstream-radar.mjs`）双向校验：
设计文档声明的编号必须在这里出现，这里出现的编号也必须在设计文档里声明。

**为什么必须登记**：偏离是设计取舍，不是缺陷。不登记的话，下一次审计会把
「故意不一样」当成 bug 修回去，或者老用户会把它当回归上报。

| ID | 维度 | 上游行为 | 重写行为 | 理由 | 上游是否已修 |
| --- | --- | --- | --- | --- | --- |
| DIV-01 | 数据归属 | 浏览器 IndexedDB（`infinite-canvas` 库，唯一真源） | 服务端 Workspace + 画布文档（浏览器仅缓存） | 多端 / 备份 / 可审计 | 不适用（上游定位是本地优先工具） |
| DIV-02 | 凭据 | 前端 localStorage 存 API Key 并直连第三方 | 服务端 AES-GCM 加密存储，接口只回显掩码，前端永不接触明文 | 安全（INV-5）：一次 XSS 即泄露全部 Key | 上游 v0.17.0 收紧了**本机 Agent** 的令牌传递，但仍不收口模型 Key 的前端持有 |
| DIV-03 | 自定义调用脚本 | 浏览器 `new Function` 注入 17 个变量 | 服务端沙箱（goja / 子进程 + 能力白名单），未落地前显式 `not_implemented` | 安全：浏览器内等价任意代码执行 | 上游 v0.18.0 仍在浏览器执行，仅把编辑器改成全屏分步 |
| DIV-04 | 插件运行 | 同源 `Blob URL + import()` 在主页面执行 | `iframe sandbox="allow-scripts"`（不加 `allow-same-origin`）+ 权限声明 + 扩大权限重确认 | 安全（INV-6） | 未修 |
| DIV-05 | 生成语义 | 一次性 `await`，失败整段重试 | `Run / Step / Attempt` 三层，输入快照、重试分类、微元计量 | 可追溯、可限额、可重放 | 上游 v0.15.0 起支持单张重试，但仍无 Run 概念 |
| DIV-06 | 同步 | WebDAV 四域，按 `updatedAt` 取新 + 删除墓碑不复活 | 服务端权威 + op 日志 + 版本号（冲突分「可 rebase / 需裁决」两档） | 一致性：时钟回拨会让时间戳合并永久偏向伪造方 | 上游 v0.18.0 修了「墓碑不复活」，语义已被本仓 8.14 对等承接 |
| DIV-07 | 错误语义 | 前端从 `message` 文本猜语义 | 稳定 `code` 枚举（21 个）+ zh-CN/en-US 文案 | 可本地化、可测试、可断言 | 未修 |
| DIV-08 | 参数表单 | 每种能力一套弹层组件 | schema 驱动，新增模型零改前端 | 维护成本 | 未修 |
| DIV-09 | 多结果 | `images[]` + `primaryImageId` 指针 | 变体集合 `Variants[]` + `Primary`，无父子里程碑补丁字段 | 去掉「主图指针 + 子节点」双真相 | 上游 v0.15.0 收敛为可展开单节点，方向一致但结构不同 |
| DIV-10 | 品牌与统计 | 赞助商 banner / 社群入口 / GA4+百度统计 | 无外链推广与统计脚本，以致谢替代 | 商业关系不随 MIT 代码继承 | 不适用（上游是主动加入） |

## 用法

1. **实现一个与上游不同的行为前**：先在 `docs/design/12` §5 加一行 DIV，再动代码。
2. **上游同步巡检报出契约变化时**：逐条对照本表，判断是「上游追上了我们的做法」
   还是「出现了新的偏离」——前者更新本表最后一列，后者新增 DIV 并进 `sync-log.md`。
3. **老用户迁移**：`docs/design/12` §6 的迁移向导要把本表的 DIV-01/02/06/07 用
   用户能理解的话讲清楚（「你的 Key 现在存在服务端」「同步不再走 WebDAV」）。
